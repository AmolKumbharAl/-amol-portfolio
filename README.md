# Amol Kumbhar — AI/ML Portfolio

A responsive, dark premium portfolio with CSS 3D-inspired motion and lightweight JavaScript.

## Run locally
1. Extract `amol_ai_ml_portfolio.zip`.
2. Open the folder.
3. Double-click `index.html` to preview in your browser.

No build tools or paid services are required. Google Fonts load from the internet; the site still works with fallback fonts if offline.

## Personalize before publishing
Open `index.html` and replace:
- `your.email@example.com` with your real email address.
- `https://www.linkedin.com/` with your LinkedIn profile URL.
- `https://github.com/` with your GitHub profile URL.
- Project links currently point to the contact section; replace them with the correct GitHub repository URLs when ready.
- Add your actual resume PDF link if you want a resume download button.

Check that every skill and project description accurately reflects your current experience. Add screenshots, source-code links and verified project results.

## Free hosting
You can publish this static site with GitHub Pages:
1. Create/sign in to GitHub.
2. Create a public repository named `amol-portfolio` (or another name).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
4. Open repository **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the published URL shown in the Pages section.

## Files
- `index.html` — page structure and portfolio content
- `styles.css` — responsive layout, visual design and CSS animations
- `script.js` — mobile menu, scroll reveal and rotating hero text
